# Contribuer

On ne pousse jamais directement sur `main` : tout passe par une branche et une pull request.

## Branches

Format : `type/description`

Exemples : `feat/filtre-prix`, `fix/stock-negatif`, `docs/readme`

## Commits

Format : `type: description`

Types : `feat` (nouveauté), `fix` (correction), `docs` (documentation), `test` (tests)

## Pull request

1. Créer une branche depuis `main`
2. Faire ses commits
3. Pousser la branche et ouvrir une pull request vers `main`
4. Merger quand tout est bon
5. Supprimer la branche
